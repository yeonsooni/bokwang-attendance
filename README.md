# 보광중앙교회 청년부 출석부

이름 격자를 탭해서 출석을 체크하고, 소그룹을 배치하고, 통계로 챙길 사람을 찾아내는 웹앱입니다.
빌드 도구 없이 HTML/CSS/JS 파일만으로 동작합니다.

```
index.html      화면 구조
styles.css      디자인 토큰 + 스타일 (라이트/다크 자동)
app.js          전체 로직 (저장소, 화면, 통계, 차트)
firestore.rules Firebase 보안 규칙
icon.svg        앱 아이콘
```

---

## 1. 바로 써보기 (로컬 모드)

```bash
cd ~/bokwang-attendance
python3 -m http.server 5173
```

브라우저에서 `http://localhost:5173` 을 엽니다.
이 상태에서는 **그 브라우저에만** 데이터가 저장됩니다. 혼자 테스트할 때 쓰세요.

> `index.html` 을 더블클릭해서 여는 방식(`file://`)은 동작하지 않습니다.
> JS 모듈은 반드시 웹서버를 통해 열어야 합니다.

## 2. 여러 명이 공유하도록 만들기 (Firebase)

리더 여러 명이 각자 폰으로 같은 출석부를 실시간으로 보게 하는 설정입니다. **무료 범위**로 충분합니다.

### 2-1. Firebase 프로젝트 만들기

1. <https://console.firebase.google.com> 접속 → **프로젝트 추가**
2. 이름은 아무거나 (예: `bokwang-youth`). Google 애널리틱스는 **사용 안 함**으로 두면 간단합니다.

### 2-2. Firestore 데이터베이스 켜기

1. 왼쪽 메뉴 **빌드 → Firestore Database** → **데이터베이스 만들기**
2. 위치는 `asia-northeast3 (서울)` 추천
3. **프로덕션 모드**로 시작 (규칙은 다음 단계에서 넣습니다)

### 2-3. 익명 로그인 켜기

왼쪽 메뉴 **빌드 → Authentication** → **시작하기** → **로그인 방법** 탭 → **익명(Anonymous)** → 사용 설정 → 저장

### 2-4. 보안 규칙 넣기

**Firestore Database → 규칙** 탭을 열고, 이 저장소의 `firestore.rules` 내용을 통째로 붙여넣은 뒤 **게시**를 누릅니다.

### 2-5. 웹앱 등록하고 설정값 복사

1. 왼쪽 위 **⚙ 프로젝트 설정** → 아래로 스크롤 → **내 앱** → **웹(`</>`)** 아이콘 클릭
2. 앱 닉네임 입력 후 등록 (호스팅 설정은 체크하지 않아도 됩니다)
3. 화면에 나오는 `firebaseConfig = { ... }` 부분을 **중괄호 포함해서 복사**

### 2-6. 앱에 붙여넣기

1. 출석부 앱 우측 상단 **⚙ 설정** → **여러 명이 공유하도록 설정**
2. **방 코드**: 자동 생성된 값을 그대로 쓰거나 직접 정합니다 (예: `bokwang-youth-2026`)
   – 이 코드를 아는 사람끼리 같은 출석부를 봅니다. 리더들에게만 알려주세요.
3. **firebaseConfig**: 2-5에서 복사한 내용을 붙여넣습니다 (`{ apiKey: "…" }` 형태 그대로 OK)
4. **저장하고 새로고침**

헤더의 점이 초록색으로 바뀌고 `공유 중 · 방 코드` 가 뜨면 성공입니다.
다른 기기에서도 **같은 주소 + 같은 방 코드 + 같은 firebaseConfig** 를 넣으면 즉시 같은 데이터가 보입니다.

> 이미 로컬 모드로 입력해 둔 명단이 있다면, 전환 **전에** 설정 → *데이터 내보내기*로 JSON을 받아두고,
> 전환 **후에** 설정 → *백업 불러오기*로 붙여넣으면 그대로 옮겨집니다.

## 3. 인터넷에 올리기

정적 파일뿐이라 아무 데나 올라갑니다. 가장 쉬운 두 가지:

**Netlify Drop** — <https://app.netlify.com/drop> 에 `bokwang-attendance` 폴더를 드래그하면 끝. 주소가 바로 나옵니다.

**Firebase Hosting** — 이미 Firebase를 쓰고 있다면:

```bash
npm install -g firebase-tools
firebase login
cd ~/bokwang-attendance
firebase init hosting     # public 디렉터리는 . (현재 폴더), SPA 아니오
firebase deploy
```

올린 뒤 폰 브라우저에서 열고 **공유 → 홈 화면에 추가** 하면 앱처럼 전체화면으로 쓸 수 있습니다.

## 4. 사용법

화면 아래 바에 **출석 · 통계 · 소그룹** 세 탭이 있습니다.

### 출석 탭
- 이름을 **탭** → 그날 출석 체크 (파랗게 칠해짐)
- 이름을 **길게 누르기**(0.55초) → 카드가 들립니다. 그대로 떼면 메뉴(이름 수정 / 소그룹 정하기 /
  장기 부재 / 삭제), 들린 채로 끌면 **순서 바꾸기**입니다.
- 명단 **맨 뒤의 회색 + 카드** → 이름 추가. 줄바꿈이나 쉼표로 여러 명 한 번에 넣을 수 있습니다.
- 날짜는 **‹ ›** 로 일주일씩, 가운데 날짜를 누르면 달력에서 직접 고릅니다. 기본값은 가장 최근 주일.
- 맨 위 카드에 그날 출석 인원과 출석률이 함께 나옵니다.
- 명단 아래 **저장 바** — 체크는 누를 때마다 이미 자동 저장되지만, 확인하고 싶으면 누르세요.
  저장소에서 실제로 다시 읽어 화면과 대조하고 결과를 알려줍니다 (보여주기용 버튼이 아닙니다).
- 헤더의 **메모 아이콘** — 그날의 특이사항을 남깁니다. 메모 수가 아이콘 위 배지로 뜨고,
  메모는 날짜별로 따로 보관됩니다.
- 명단 정렬 기준 3가지 — 고른 값은 기기에 기억됩니다.
  - **가까이 앉는 대로** — 예배당에서 앉는 순서. 이 정렬에서만 **카드를 끌어 순서를 바꿀 수
    있습니다** (가나다순·소그룹별은 계산으로 나오는 순서라 고정). 길게 눌러 카드를 들어올린 뒤
    끌면 주변 카드가 스르륵 비켜서고, 놓으면 그 자리에 안착합니다. 위아래 끝으로 끌면 목록이
    따라 스크롤됩니다. 자리 번호가 없는 사람은 이름순으로 맨 뒤에 붙습니다.
  - **가나다 순** — 이름 오름차순
  - **소그룹별** — 조 단위로 묶여서 `4/6` 처럼 조별 현황이 함께 보입니다

### 장기 부재 (군 복무 · 유학 등)
못 오는 게 정상인 사람이 "챙겨야 할 사람"에 뜨면 목록이 쓸모없어지므로, 따로 표시합니다.
명단에서 지우는 게 아니라 **통계에서만 빠지고 기록은 그대로 남습니다.**

- 이름을 길게 누르고 **「○월 ○일부터 장기 부재」** → 사유 선택 (군 복무 / 유학 / 타지 거주 / 건강 / 장기 출타 / 직접 입력)
- 명단 격자에서 빠져 화면 아래 **장기 부재** 칸으로 내려갑니다. 들르면 거기서 그대로 체크할 수 있습니다.
- 돌아오면 다시 길게 눌러 **「○월 ○일부터 복귀」**

**핵심은 이게 플래그가 아니라 기간이라는 점입니다.** 부재 시작일과 복귀일을 각각 기억하므로,
8/16에 복귀시켜도 8/9로 넘겨보면 그 주에는 여전히 장기 부재로 남아 있습니다. 기준은 항상
**보고 있는 주**입니다 — 8/9을 열어둔 채 부재 처리하면 8/9부터 적용됩니다.

통계에서는 이렇게 다뤄집니다.

- 출석률 분모에서 그 주에 부재였던 사람은 빠집니다 (61명 → 59명 하는 식으로 주마다 달라짐)
- 부재 기간의 주는 그 사람의 **연속 결석·출석률 계산에서 통째로 제외**됩니다.
  군 복무 2년 뒤 복귀한 사람이 "연속 100회 결석"으로 잡히지 않습니다.
- 개인별 출석률의 점 그래프에서 부재 주는 빗금으로 표시됩니다 (결석과 구분)
- **주별 출석 수 막대는 그대로입니다** — 실제로 참석한 인원 수이고, 부재 처리 전에 온 기록은 사실이므로

한 사람당 부재 기간은 하나만 기억합니다. 다시 부재 처리하면 이전 기간을 덮어씁니다.

### 소그룹 탭
- 맨 위 **편성 현황** — 소그룹 수 / 배정됨 / 미배정과 배정 진행 막대
- 조마다 소속된 사람이 칩으로 나옵니다. 칩을 누르면 다른 조로 옮길 수 있습니다.
- 조 이름 옆 **⋯** → 이름 수정 / 소그룹 삭제
- 맨 아래 **+ 소그룹 만들기**
- 소그룹을 지워도 사람과 출석 기록은 남고 **미배정**으로만 이동합니다.
- 출석 탭에서 이름을 길게 눌러 **소그룹 정하기**로도 같은 작업을 할 수 있습니다.

### 통계 탭
- **주별 출석 수** — 최근 12회 모임의 출석 인원. 막대를 누르면 그 주의 상세가 아래에 뜹니다.
- **소그룹별 출석률** — 최근 8회 기준, 조 인원 대비 출석률과 주당 평균 참석 인원.
- **챙겨야 할 사람** — 연속 3~4회 결석.
- **잘 나오다가 갑자기 안 나온 사람** — 출석 빈도가 확 떨어진 분. 연속 결석과는 다른 기준입니다.
- **발걸음이 뜸한 사람** — 연속 5회 이상 결석.
- **개인별 출석률** — 최근 12회를 점으로 표시, 낮은 사람부터 정렬.

### 챙겨야 할 사람 / 발걸음이 뜸한 사람 — 계산 방식
**연속 결석 회수**만으로 두 단계로 나눕니다.

| 연속 결석 | 분류 | 색 띠 |
|---|---|---|
| 3~4회 | **챙겨야 할 사람** — 지금 연락하면 돌아오기 좋은 시점 | 4회 주황 / 3회 노랑 |
| 5회 이상 | **발걸음이 뜸한 사람** — 한동안 못 뵌 분 | 빨강 |

각 목록은 **오래 빠진 순서**로, 같으면 평소 출석률이 높던 사람 순서로 정렬됩니다.
각 줄에는 마지막 출석일, 그 전 8회 출석률, 전체 출석률, 최근 12회 점 그래프가 함께 나옵니다.

**잘 나오다가 갑자기 안 나온 사람**은 이와 별개의 기준입니다. 이전 8회를 **절반 이상** 나오던 분 중
최근 4회 출석률이 **35%p 이상** 떨어진 경우를 잡습니다. 연속 결석이 아니라 빈도 변화를 보기 때문에,
매주 오다 3주 내리 빠진 분뿐 아니라 매주 오다 격주로 바뀐 분도 걸립니다.

두 가지 예외 처리가 있습니다.

- **첫 출석 이전 기간은 연속 결석에 세지 않습니다** — 늦게 합류한 사람이 "몇 달째 결석"으로 잡히지 않습니다.
- **한 번도 출석 기록이 없는 사람은 두 목록 어디에도 오르지 않습니다.** 발걸음이 뜸해진 것이 아니라
  애초에 온 적이 없는, 성격이 다른 챙김이기 때문입니다. 대신 *발걸음이 뜸한 사람* 카드 맨 아래에
  이름을 따로 모아 보여줍니다.

### 엑셀에서 가져오기
구글 폼 응답 시트(`주일 예배 출석인원 [이름]` 형식)는 `import/` 폴더의 변환 결과를
**⚙ 설정 → 백업 불러오기 → 파일 선택**으로 넣으면 됩니다.

## 5. 구글 시트로 자동 저장

출석을 체크할 때마다 지정한 구글 시트가 자동으로 최신 상태가 됩니다.
폰·PC 어디서든 시트를 열면 되고, 시트에서 바로 엑셀로 내려받을 수도 있습니다.

만들어지는 탭 세 장:

| 탭 | 내용 |
|---|---|
| **출석표** | 이름 × 날짜 표. `O` 출석 / 빈칸 결석 / `부재` 장기 부재. 소그룹·출석횟수·출석률 포함 |
| **주별 요약** | 날짜별 출석 인원·전체·출석률과 **그날의 메모** |
| **소그룹** | 조별 인원과 명단 |
| 갱신기록 | 언제 갱신됐는지 자동 기록 |

설정은 `google-sheet/Code.gs` 맨 위 주석에 단계별로 적어뒀습니다. 요약하면:
구글 시트 새로 만들기 → 확장 프로그램 → Apps Script 에 그 파일 붙여넣기 → `SECRET` 바꾸기 →
배포(웹 앱 / 실행: 나 / 액세스: 모든 사용자) → 나온 URL 과 SECRET 을
**⚙ 설정 → 구글 시트로 자동 저장** 에 입력.

동작 방식 두 가지를 알아두시면 좋습니다.

- **전체 덮어쓰기**입니다. 매번 표 세 장을 통째로 다시 씁니다. 중간에 전송이 한 번 실패해도
  다음 전송에서 그대로 회복되고, 부분 갱신에서 생기는 어긋남이 없습니다.
  그래서 **시트에 직접 적은 내용은 다음 전송 때 지워집니다** — 메모는 앱의 메모 기능을 쓰세요.
- 연달아 체크할 때는 **2.5초 모아서 한 번만** 보냅니다. 명단을 쭉 훑어도 요청은 한 번입니다.

전송 상태는 명단 아래 저장 바에 함께 나옵니다 (`방금 저장 · 시트 반영됨`).
실패하면 빨갛게 바뀌고, 저장 바를 누르면 즉시 다시 보냅니다.

## 6. 백업 · 내보내기

**⚙ 설정**에서:
- **데이터 내보내기** — 전체를 JSON 파일로 저장 (기기 이전, 사고 대비)
- **출석표 CSV 내려받기** — 엑셀에서 바로 열리는 표 (이름 × 날짜, 출석횟수·출석률 포함)
- **백업 불러오기** — 내보낸 JSON을 붙여넣어 복원 (**기존 데이터는 대체됩니다**)
- **전체 초기화** — 연습용 데이터를 지우고 실제 명단으로 시작할 때 사용

## 7. 보안에 대해

이 앱의 접근 통제는 **방 코드를 아는 사람만 접근**하는 수준입니다.
익명 로그인을 통과한 사용자는 방 코드를 알면 그 방을 읽고 쓸 수 있습니다.
