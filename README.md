# 보광중앙교회 청년부 출석부

이름을 탭해서 출석을 체크하는 모바일 웹앱. 리더 몇 명이 함께 쓰고, 기록은 엑셀로 받습니다.

```
index.html           화면 구조
styles.css           디자인
app.js               전체 로직
firebase-config.js   Firebase 설정 (설정 전에는 null)
firestore.rules      보안 규칙 — Firebase 콘솔에 붙여넣을 내용
google-sheet/Code.gs 구글 시트 자동 전송 (선택)
```

명단·출석 기록 같은 개인정보는 이 저장소에 **없습니다** (`.gitignore`).

---

## 설정 (한 번만, 약 10분)

설정 전에는 앱이 "이 기기에만 저장" 모드로 돕니다. 혼자 써보는 건 바로 됩니다.
여러 명이 함께 쓰려면 아래를 따라 하세요.

### 1. Firebase 프로젝트 만들기
<https://console.firebase.google.com> → **프로젝트 추가** → 이름 아무거나 (예: `bokwang-youth`)
→ Google 애널리틱스는 **사용 안 함**

### 2. 데이터베이스 켜기
왼쪽 **빌드 → Firestore Database** → **데이터베이스 만들기**
→ 위치 `asia-northeast3 (서울)` → **프로덕션 모드**

### 3. 보안 규칙 넣기
**Firestore Database → 규칙** 탭 → 이 저장소의 `firestore.rules` 내용을 전부 붙여넣고 **게시**

> 이게 핵심 보안 장치입니다. 로그인한 계정만 데이터를 읽고 쓸 수 있게 막습니다.

### 4. 리더 계정 만들기
왼쪽 **빌드 → Authentication** → **시작하기**
→ **로그인 방법** 탭에서 **이메일/비밀번호**만 사용 설정 (구글·익명 등은 켜지 마세요)
→ **Users** 탭 → **사용자 추가** 로 리더 4~5명의 이메일·비밀번호를 직접 만듭니다

> 앱에는 가입 기능이 없습니다. 여기서 만든 계정만 들어올 수 있습니다.

### 5. 앱에 설정값 넣기
**⚙ 프로젝트 설정** → 아래로 스크롤 → **내 앱** → **웹 `</>`** → 앱 등록
→ 나오는 `firebaseConfig = { ... }` 를 복사해서 `firebase-config.js` 에 붙여넣습니다.

```js
export const FIREBASE_CONFIG = {
  apiKey: "AIza...", authDomain: "...", projectId: "...", appId: "..."
};
```

이 값들은 **비밀이 아닙니다.** 공개돼도 됩니다 — 보안은 3번 규칙과 4번 계정이 담당합니다.

### 6. 명단 넣기
아무 리더 계정으로 로그인한 뒤 **⚙ 설정 → 백업 불러오기 → 파일 선택** 로
`import/` 폴더의 JSON 을 넣으면 명단·출석 기록·소그룹·자리 순서가 한 번에 들어갑니다.
한 명만 넣으면 나머지 리더 폰에도 자동으로 퍼집니다.

## 쓰는 법

화면 아래 **출석 · 통계 · 소그룹** 세 탭.

### 출석
- 이름 **탭** → 출석 체크. 누르는 즉시 저장되고 다른 리더 화면에도 바로 반영됩니다.
- 이름 **길게 누르기** → 카드가 들립니다. 그대로 떼면 메뉴(이름 수정 / 소그룹 / 장기 부재 / 삭제),
  들린 채로 끌면 **순서 바꾸기** (자리 순 정렬에서만).
- 맨 뒤 **회색 + 카드** → 이름 추가 (줄바꿈·쉼표로 여러 명 한 번에)
- 날짜는 **‹ ›** 로 한 주씩, 가운데를 누르면 달력
- 명단 정렬 — **가까이 앉는 대로 / 가나다 순 / 소그룹별**
- 헤더 **메모 아이콘** → 그날의 특이사항. 메모 수가 배지로 뜹니다.
- **⚙ 설정 → 화면 색** — 5가지 중에 고릅니다. **기기마다 따로 기억**되므로
  리더별로 다르게 써도 됩니다. `preview.html` 에서 로그인 없이 미리 비교할 수 있습니다.
  - *기본 블루* — 진하게 채워 또렷합니다
  - *옅은 블루 · 세이지 · 먹색 · 테라코타* — 눈이 편한 대신 구분이 약해 테두리로 보완했습니다
- 명단 아래 **저장 바** → 눌러보면 저장소에서 다시 읽어 화면과 대조해 줍니다.

### 장기 부재 (군 복무 · 유학 등)
못 오는 게 정상인 사람이 "챙겨야 할 사람"에 뜨면 목록이 쓸모없어지므로 따로 표시합니다.
이름을 길게 눌러 **「○월 ○일부터 장기 부재」**, 돌아오면 **「○월 ○일부터 복귀」**.

**플래그가 아니라 기간입니다.** 8/16에 복귀시켜도 8/9로 넘겨보면 그 주에는 여전히 부재로
남습니다. 부재 기간의 주는 그 사람의 연속 결석·출석률 계산에서 통째로 빠지므로,
군 복무 2년 뒤 복귀한 사람이 "연속 100회 결석"으로 잡히지 않습니다.

### 통계
주별 출석 수 · 소그룹별 출석률 · 개인별 출석률과, 챙길 사람을 세 갈래로 나눠 보여줍니다.

| | 기준 |
|---|---|
| **챙겨야 할 사람** | 연속 3~4회 결석 — 지금 연락하기 좋은 시점 |
| **발걸음이 뜸한 사람** | 연속 5회 이상 결석 |
| **잘 나오다가 갑자기 안 나온 사람** | 이전 8회를 절반 이상 나오던 분이 최근 4회에 35%p 이상 하락 |

첫 출석 이전 기간은 세지 않고, 한 번도 안 온 사람은 목록에 넣지 않습니다
(성격이 다른 챙김이라 이름만 따로 모아 보여줍니다).

### 소그룹
편성 현황(조 수 / 배정 / 미배정)과 조별 명단. 칩을 눌러 조를 옮기고, **⋯** 로 이름 수정·삭제.

## 엑셀로 받기

**⚙ 설정 → 엑셀 파일로 내려받기** → 시트 3장짜리 `.xlsx` 가 받아집니다.

| 시트 | 내용 |
|---|---|
| 출석표 | 이름 × 날짜. `O` 출석 / 빈칸 결석 / `부재` 장기 부재 + 출석횟수·출석률 |
| 주별 요약 | 날짜별 출석·전체·출석률과 그날의 메모 |
| 소그룹 | 조별 인원과 명단 |

매주 자동으로 쌓이길 원하면 **⚙ 설정 → 구글 시트로 자동 저장** 도 있습니다.
설정 방법은 `google-sheet/Code.gs` 맨 위 주석에 있습니다. 체크할 때마다 지정한 구글 시트가
최신 상태로 덮어써집니다 (전체 덮어쓰기라 시트에 직접 적은 내용은 지워집니다).

## 설정

헤더의 **톱니 아이콘**을 누르면 설정이 **독립 화면**으로 열립니다 (팝업이 아닙니다).
같은 자리의 **✕** 를 누르거나 아래 탭을 누르면 나옵니다.

| 구역 | 내용 |
|---|---|
| **계정** | 로그인한 아이디 · 비밀번호 변경 · 로그아웃 |
| **파일** | 엑셀 내려받기 · 구글 시트 자동 저장 · 전체 백업(JSON) · 백업 불러오기 |
| **화면 색** | 5가지를 그 자리에서 바로 고릅니다 (누르면 즉시 적용) |
| **되돌릴 수 없음** | 전체 초기화 — **비밀번호를 다시 입력해야** 실행됩니다 |

### 전체 초기화
지워지는 양(명단 · 주 · 메모)을 숫자로 먼저 보여주고, **먼저 백업 받기** 버튼을 함께 둡니다.
실행하려면 **로그인한 본인 계정의 비밀번호**를 한 번 더 입력해야 합니다 (Firebase 가 서버에서 검증).

> 관리자 암호를 코드에 넣지 않은 이유: 이 저장소는 공개라 누구나 값을 볼 수 있습니다.
> 계정 비밀번호는 코드에 없고 서버에서만 확인되므로 실제로 안전합니다.

## 보안에 대해

- 앱 주소는 공개돼도 됩니다. 계정이 없으면 **로그인 화면 너머로 아무것도 안 보입니다.**
- 데이터를 읽고 쓸 수 있는 건 **이메일/비밀번호로 로그인한 계정**뿐입니다 (`firestore.rules`).
  익명 로그인은 쓰지 않습니다.
- 앱에 **가입 기능이 없습니다.** 계정은 Firebase 콘솔에서 관리자가 직접 만듭니다.
- 이 저장소에는 명단·출석 기록이 들어 있지 않습니다.
- 리더가 청년부를 떠나면 Firebase 콘솔 → Authentication → Users 에서 계정을 삭제하세요.
